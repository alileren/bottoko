# bottoko

Perintah yang dapat digunakan:
- `!products` untuk menampilkan semua produk
- `!category` untuk menampilkan semua kategori produk
- `!product <category>` untuk menampilkan produk dari kategori tertentu
- `!detail <nama_produk>` untuk menampilkan detail produk seperti gambar, nama produk, kategori, ukuran, harga per unit, diskon
- `!addtocart <nama_produk>` untuk menambahkan barang ke keranjang
- `!carts` untuk melihat semua barang di keranjang
- `!checkout` untuk checkout semua barang di keranjang
    
    Ketika checkout, nanti akan tampil daftar barang beserta harganya dan total harganya.

    Bot akan meminta user untuk memasukkan alamat jika user belum memasukkan alamat

    Setelah itu, akan muncul QR code dan no rekening bank milik toko.

    Setelah membayar (tidak perlu real payment, nanti anggap saja sudah bayar), maka bot akan menyampaikan bahwa pembayaran berhasil dan barang akan dikirim.
